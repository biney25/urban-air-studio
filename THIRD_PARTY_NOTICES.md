# Third-party credits

Cedar/cedarpy notices, Apache licence and upstream native SBOMs are retained in third_party/cedar. OpenFOAM Foundation/CFD Direct and GPL-3.0-or-later original linked native utilities are identified in third_party/openfoam. Only utility source is included; no installed solver/helper binaries are redistributed.

Locked Python dependencies and direct frontend/development dependencies retain available installed licence texts under third_party/python and third_party/node. Names, versions and declared licences are recorded in dependency-license-inventory.json. Dependency installers retain upstream package notices. This inventory is not a blanket legal certification or an application licence. No new permissions for original app code are granted here. Original product documents and external benchmark data remain local and excluded.

New deadline component notices: Strands/Ollama/Qwen and their installed dependency notices are retained under third_party/assistant with a separate inventory. Licensed Poppins/Inter font files, exact provenance and SIL Open Font License texts are under web/public/fonts. The current locked Python and direct Node package notice inventory includes MapLibre; its BSD-3-Clause licence is retained under third_party/node/maplibre-gl. Model weights, installed binaries, user/profile keys and private inference messages are not included.
