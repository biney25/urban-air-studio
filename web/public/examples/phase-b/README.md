# Illustrative evidence request templates

These locally authored fictional examples exist for software workflow checks. They contain no measured site evidence, calibrated emission factors, independently attested model predictions or reviewer approval.

Each example is explicitly classified as illustrative and grants derive, solve and export permissions for this fictional fixture. Replace the provenance and permission declarations with the actual source terms when importing other data. Do not relabel these values as observed measurements or qualified results.

Replay templates need the actual saved campaign or protocol ID selected in the Evidence workspace. The placeholder bindings are not valid saved records. Prediction examples declare interval means; Phase A end-state fields cannot be reused as interval means.
